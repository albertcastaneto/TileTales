# TileTales - Slide Your Time Away

A relaxing picture sliding puzzle by koidafish. Slide pieces in the empty space's row or column, through the spare slot
above the grid, to rebuild the picture.

- 42 bundled pictures in 14 categories (Original and Fairy-Tale collections), each with Beginner (3×3), Intermediate (4×4)
  and Advanced (6×6) levels, unlocked by solving puzzles. Players can also use their own photo.
- Tap or swipe pieces, hold to peek at the finished picture, light and dark themes, sound and vibration.

## Projects in this repo

| Folder | What it is |
| --- | --- |
| [`godot/`](godot/) | The Android game (Godot 4.7), with AdMob banner and rewarded ads. See [godot/README.md](godot/README.md) for running, ads setup and export. |
| [`www/`](www/) | The original web version (single `index.html`), installable as a PWA. Run `npm run dev` and open http://localhost:4173. See [HANDOFF.md](HANDOFF.md). |

Pictures live in both `www/images/` and `godot/assets/images/`; keep them in sync when adding new ones.
